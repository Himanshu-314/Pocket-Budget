POCKET BUDGET - INSTALLABLE WEB APP

IMPORTANT: A local HTML file cannot be installed as a proper home-screen app in Chrome. Host this folder on an HTTPS static site first.

EASIEST METHOD (GitHub Pages):
1. On a computer, sign in to GitHub and create a new PUBLIC repository named pocket-budget.
2. Upload index.html, manifest.webmanifest, sw.js, and the icons folder (including both PNG files) to the repository root.
3. In repository Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
4. Wait for GitHub Pages to publish the site. Open the provided https://...github.io/... URL on your Android phone in Chrome.
5. Tap Chrome menu (⋮) > Install app, or Add to Home screen.

Your data is stored in the browser on that website/device. It will not automatically migrate from the old local HTML file. Export a backup from the old app before switching, if that feature is available.
